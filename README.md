### 存檔說明（兩個遊戲相同）
- 成績、熟練度、名字都**自動存在這台裝置的這個瀏覽器**，不會上傳到任何伺服器。
- 以下情況會看不到原本進度：換手機／電腦、換瀏覽器（例如 Chrome 換 Safari）、無痕模式、清除瀏覽資料。
- 換裝置：在舊裝置選單「🔄 換裝置／備份進度」按「📋 複製進度代碼」（或「💾 下載進度檔」，含逐題紀錄），到新裝置貼上後按「⬇ 匯入代碼」（或「📂 選擇進度檔」）。
- 匯入是**合併**，不會蓋掉新裝置已有的紀錄；同一個單字以較新的結果為準。
- 建議偶爾備份一次進度代碼（例如傳到自己的 LINE）。
